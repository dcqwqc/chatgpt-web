# Public release checklist

- [ ] Rights to redistribute upstream-derived code are clarified and documented.
- [ ] Supported Python and Node test suites pass on clean CI runners.
- [ ] Public tree scan finds no tokens, local user paths, private IPs, browser data, account IDs or secrets.
- [ ] README, examples, and configuration are machine-independent.
- [ ] A disposable authenticated conversation smoke test succeeds.
- [ ] Actual BB countdown and cancellation are visually verified without disturbing running work.
- [ ] Release version and artifacts are inspected before publishing.
- [ ] Upstream PRs contain focused, independent fixes.

Development can continue in this public GitHub fork, but do not advertise a redistributable licensed release until the licensing blocker is resolved.
